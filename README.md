## ✨ Key Feature Highlights

### 🎬 1. Cinema-Grade Hero Stage
- **Hardware-Accelerated Video Canvas**: Ultra-smooth looping MP4 video background with film grain, radial vignette, and custom dark-gold horizon lines.
- **Sculpted Typography**: Custom font pairing utilizing `Bebas Neue` for high-impact industrial headlines, `Montserrat` for editorial balance, and `JetBrains Mono` for developer precision.

### 🃏 2. Vertical 3D Overlapping ScrollStack
- **Physics-Driven Card Stacking**: Smooth card pinning where each project and academic milestone slides smoothly into an overlapping deck based on window scroll progress.
- **Independent Scroller Scope**: Multi-instance isolation allowing both **Selected Works** and **Academic Background** to stack independently without event collision.
- **Quick-Jump Milestone Bar**: Interactive pills allowing instant navigation to any card in the stack with smooth scrolling and visual indicators.

### 🗂️ 3. Horizontal Overlapping Certification Deck
- **Card-Fan Sliding Layout**: Certifications overlap horizontally from left to right with responsive offsets and elevation shadows.
- **Deep Inspection Modals**: Click any credential to launch a modal viewer with PDF embedding, zoom controls, credential metadata, and fallback viewports.

### 📜 4. Interactive Resume & Credential Viewer
- Full-screen in-app modal viewports with multi-engine rendering (interactive `<iframe>`, `<embed>`, and fallback anchors).
- Instant download buttons and verification badges for all certificates (AI Winter & Summer Internships, Full Stack Development, Cloud Computing, DBMS, Java, McKinsey Forward, and SageX).

### ⚡ 5. Real-Time Encrypted Transmission (Contact Form)
- **Direct Mail Delivery**: Form submits directly to `dipanshuraj0708@gmail.com` using FormSubmit AJAX API.
- **Zero Page Reloads**: Built with asynchronous states:
  - `Loading`: Displays animated encrypted packet indicator.
  - `Confirmed`: Renders packet transmission confirmation with reset triggers.
  - `Resilience Fallback`: Automatic fallback to direct `mailto:` handler if connectivity drops.
- **Direct Channel Matrix**: Verified direct email, WhatsApp phone hotline (`+91 8092870903`), and availability status badge.

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version `18.0.0` or higher recommended)
- `npm` or `pnpm` / `yarn`

### 1. Clone the Repository
```bash
git clone https://github.com/RjDipanshu/Cinematic_Portfolio.git
cd Cinematic_Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Launch Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the application with Hot Module Replacement (HMR).

### 4. Build for Production
```bash
npm run build
```
Creates an optimized, minified production bundle in the `dist/` directory ready for deployment to Vercel, Netlify, or GitHub Pages.
